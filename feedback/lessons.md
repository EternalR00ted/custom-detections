# Lessons from denied drafts

One line per lesson, starting with "- ". The blue side reads the last 40 on
every Draft rules run. Add them with the deny command in the setup guide
(Step 10), which opens a small pull request for each.

- Don't exclude a host, user, path or tool just because the source names it. That hides the activity the source describes.
- Match the behavior (parent and child process, command-line pattern), not file hashes or IP addresses from the article.
