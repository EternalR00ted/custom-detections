# Analyst write-ups

Each Markdown file in this folder is drafted like a threat article on the next
Draft rules run. Use it for incident reports and things you saw that no
public article covers.

Write what the attacker did, step by step: process names, command-line
pieces, parent and child processes, registry paths, files written, network
connections. Quote real command lines where you can, because the blue side
must quote the source word for word for every point it makes.

Before you commit a write-up, remove hostnames, usernames, IP addresses and
anything else that identifies your environment. The repo may be published.

Add each file in its own pull request. Once it's drafted, the pull request it
produced links back to it, and it won't be drafted again.
